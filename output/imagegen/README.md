# 情报页面设计参考

`intelligence-design-board.png` 为本次 imagegen 生成的六屏效果图；新闻、日期、数量和对话均为排版示例，不是产品数据或事实依据。

## 实现对应

- 精选：保留应用外壳与筛选组件，统一情报导航，双列阅读卡片，明确标题、摘要与来源层次。
- 解读：保留独立原文、引用和讨论区域，用分隔线与阅读底色区分依据；保留加入选题的确认流程。
- 选题：状态先于标题，字段对齐，研究入口位于行尾；窄屏转为单列。
- 资料：沿用 AI 情报待审阅、本次采集、全部资料三个真实视图；原文展开区使用白色阅读表面。
- 信源：保留分组、失败原因、暂停和编辑入口，优化行内信息层次。
- 每周回顾、处理记录、AI 热点：保持现有功能，补齐共同导航和阅读层次。

效果图中的额外搜索、导出等控件未加入产品；现有确认机制、证据校验与真实数据来源保持不变。共享导航沿用项目路由，支持键盘、修饰键打开链接与当前页提示。

浏览器验收截图位于 `workbench/output/playwright/`（从仓库根目录起）。测试使用系统临时目录中的隔离数据及明确的测试样本。
