# 情报页面设计参考

`intelligence-design-board.png` 为本次 imagegen 生成的六屏效果图；新闻、日期、数量和对话均为排版示例，不是产品数据或事实依据。

## 实现对应

以图中的内容区结构为实施依据；原有左侧栏与「精选 / 选题 / 资料」二级目录保持原样，`App.jsx`、`app-navigation.css`、`styles.css` 未修改。

- 精选：白色内容面板、页内标题和操作栏、下划线筛选、紧凑双列卡片。来源、更新时间和收藏入口可直接阅读。
- 解读：白色长文阅读区、原始依据和独立 AI 讨论栏，保留现有候选与确认流程。
- 选题：状态、选题与受众、切入角度、读者价值、证据缺口、下一步六列比较；完整研究依据可展开。手机改为带字段说明的单列。
- 资料与审阅：左侧目录、右侧阅读；长文独立滚动，原文与导读仍分开。手机选择后进入阅读，提供返回列表。
- 信源：分组表格与状态筛选；名称、采集时间、运行状态、操作分别对齐。失败原因保持可见，详细采集统计和权限可展开。
- 每周回顾：左侧周报目录与右侧正文，引用依据完整保留；手机单栏切换。
- 处理记录：主题、状态、时间对齐，展开后保留覆盖范围、失败说明与重试。
- AI 热点：按用户后续要求恢复情报改版前的居中胶囊页签与通栏列表，不使用新情报内容面板；原文阅读、收藏和缺失字段保护保留。

只使用已有真实字段；图中的额外搜索、导出或虚构新闻不加入产品。共享页头与目录阅读组件限定在情报内容区，不改变其他模块或二级导航。

浏览器截图位于 `workbench/output/playwright/`。`intelligence-redesign-live-*` 为正式工作台只读验收；其他测试使用系统临时目录中的独立数据和明确测试样本。
