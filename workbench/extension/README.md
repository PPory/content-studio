# Xenho 网页助手

在任意普通网页划取文字，直接连接本机的辛禾创作工作台。

## 安装

1. 先启动工作台：在项目目录运行 `npm run dev`，或从开始菜单打开 Xenho OS。
2. Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。
4. 首次安装时允许扩展读取网页内容。这项权限用于识别你主动选中的文字；内容不会因为安装扩展而自动入库。

## 使用

在网页上选中至少两个字，选区旁会出现 Xenho 小图标。点开后有五个入口：

- 批注：在右侧面板写想法，保存到本地知识库的 `网页批注/`。
- 提问：解释、展开、反驳，结果可再存为批注或素材。
- 对话：选择 Claude Code 或 Codex，围绕选区连续交流。
- 选题：直接把选区转成内容方向，结果显示在“提问”面板。
- 入库：不打开面板，可选择直接写入“素材库”，或先放进“灵感库”进入工作台初筛流程。

不提供高亮和翻译。

## 数据与权限

- 扩展只连接 `http://127.0.0.1:5180`，不会接触工作台的 Worker 或模型密钥。
- 选区、AI 结果和对话只暂存在当前 Chrome 会话；批注和你主动入库的内容才会落库。
- 默认只发送选区。对话中的“附带选区附近正文”需要手动勾选。
- Chrome 内部页面、Chrome 应用商店及部分浏览器内置阅读器不允许扩展注入，这是浏览器限制。

## 更新

代码更新后，在 `chrome://extensions` 找到“Xenho 网页助手”并点刷新按钮。若工作台重启，扩展会自动重新配对。
