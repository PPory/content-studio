# 发现方向与统一内容工作页

「发现方向」是创作区的可选入口，从知识和真实用户声音中寻找连接，不代表所有内容都必须走这条路径。

## 当前主路径

1. 用户主动扫描并阅读候选，比较期间不写正式内容。
2. 点击「发展这条」后，项目、空白主稿和未确认探索在一个事务中创建，重试复用同一项目。
3. 进入项目页，随时编辑构思、补材料、比较讲法或直接写正文。
4. 构思和候选存入 `project_notebooks`，关闭或刷新后恢复；正式正文仍需用户采用。

项目里的「根据这个方向生成讲法候选」复用原有生成接口。候选与来源线索留在当前项目，不重新创建机会。

## 历史入口

已保存机会、手动配对和旧构造页继续兼容已有深链与数据，不作为新建内容的默认前置流程。旧机会转项目仍幂等；旧记录不被新构思回写。

## 真实性

受众假设与原话分别显示。构思与候选不是已核验证据；写作上下文从 SQLite 重新读取材料和 Wiki。没有依据时明确说明缺口，不以保存过候选作为真实性证明。

## 验证

`tests/project-notebook.mjs` 覆盖验证、并发冲突、原子创建和重开；`tests/project-notebook-context.mjs` 覆盖无机会创作与证据读取；`tests/project-notebook-ui.mjs` 验证真实浏览器保存、刷新、切页、错误、键盘和小屏。所有写入测试仅用临时独立工作区。
