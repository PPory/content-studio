【可选结构框架】按选题气质择一使用，不必强套；**不合适就自然行文**。

STORY（适合"有人设 + 有干货"的分享）
- S 情绪钩子：用痛点开头，制造情绪共鸣。
- T 转折：抛一个反常识观点，制造认知升级。
- O 目标：描绘受众最渴望的结果 / 生活。
- R 解决方案：分享素材里已有的方法 / 经验干货；没有「个人经历」素材时不得改写成我的亲历。
- Y 行动号召：结尾 CTA，引导关注 / 行动。

S.C.O.P.E（适合"深度洞察型"）
- S 情境：描述当下状况，引起共鸣。
- C 冲突：点出隐藏的问题 / 矛盾 / 痛点。
- O 观察：分享我的观点；具体亲历发现必须有「个人经历」素材支撑。
- P 主张：提出我的观点 / 角度。
- E 案例：用真实故事、数据或案例支撑。
