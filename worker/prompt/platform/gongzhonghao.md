【平台：公众号 —— 完整深度长文】

定位：微信公众号，读者会点开、会读完、会转发到朋友圈或群。一篇要能独立成立，读完有收获。

篇幅：约 1200–2000 字。

标题：
- 正标题要有强钩子：悬念 / 反常识 / 具体数字 / 利益点，让人忍不住点开。
- 另给 2–3 个备选标题放进 alt_headlines。

开头（前 3 行定生死）：
- 用一个真实场景、一句痛点、或一个反差把人钩住，别铺垫、别讲大道理。
- 尽量从「我」的一段真实经历切入。

结构：
- 起承转合，用小标题分段，一段只讲一个点。
- 观点后面立刻跟例子/故事/数据，虚实结合，不空转。
- 段落要短，多留白，手机上读着不累。

结尾：
- 收一个可操作的行动或一句留得住的话。
- 自然地引导「关注 / 在看 / 转发」，不要硬广腔。

语言：口语化、第一人称、有温度，像在咖啡厅跟朋友讲清一件事。
