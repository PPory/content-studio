【平台：X（推特）—— 中文单语】

定位：中文 AI / 独立创作圈的信息流内容。只写中文，不出双语版、不混英文帖——账号的互动人群画像就是算法对这个号的全部认知，语言必须统一。

【算法事实 · 写法规则的依据】（来自 X 开源的 Grok 推荐算法，xai-org/x-algorithm）
- 每条帖子独立打分，thread 也只有第一条能进陌生人的信息流——第一句就是全部赌注。
- 算法预测的是真实行为概率：回复、转发、收藏、私发分享、停留时长。「让人想回一句」「值得转给朋友看」的内容才有分发。
- 负信号（拉黑、静音、「不感兴趣」）带负权重且代价不对称：宁可不发，也不发平庸、争流量或让人反感的内容。
- 正文带外链会大幅压制触达：链接一律放在自己的第一条回复（自评）里，正文保持纯文本。

【形态 · 按内容量级选，默认从简】
1. 单推（默认）：一个观点 / 一个金句 / 一组数字，一击即中。大多数内容用这个。
2. 短 thread（2–5 条）：一个观点需要展开论证、列步骤或摆证据时用。
3. 长 thread（6–10 条）：仅当素材真的撑得起（完整方法论、深度复盘），否则不要凑条数。

【高互动结构模式 · 借结构不借声音】（从高互动 AI 创作者实盘提炼，按素材气质选用，不硬套；表达必须是作者自己的，禁止套话式模仿）
1. 亲历见闻开场：「⟨具体的人/场景⟩告诉我一件我一直在想的事」→ 给现场细节 → 收在一个矛盾或张力上。一手见闻是最强钩子，没有真实见闻就不用这个模式。
2. 现象→判词两段式：第一段具体观察（谁、在哪、什么事），第二段一句狠结论，不解释。
3. 成品展示：「我做了 ⟨具体东西⟩」+ 一个大判断（「大多数人还没意识到…」）→ 一两行讲它怎么工作。做了什么就秀什么，build in public。
4. 重构式：「⟨大家都在做的事⟩解决错了问题。你不需要 X，你需要 Y。」
5. 个人叙事三拍：过去的状态 → 转折点 → 「所以我做了一件大多数人不会做的事：…」。
6. 编号干货：承诺里带具体数字（「我用 3 个月做到 ⟨结果⟩」），每条一句话，括号里给补充说明。

【写法】
- 第一句用具体数字、反常识结论、强观点或画面感场景开场；禁止「今天聊聊」「分享一下」「大家有没有发现」式软开头。
- 每条推独立成立，能被单独截图转发。短句、断行、有呼吸感。
- 具体 > 抽象：给数字、给例子、给画面，不给大道理。
- 结尾开放式：抛一个问题、一个立场、一个未尽的口子，让人想回一句——不要「点赞关注」式 CTA。
- thread 用「1/ 2/ 3/」编号，条与条之间有递进或反转，别平铺。
- 需要引导读原文时，正文不放链接，另写一条发在自评的短文案。
- 第一人称、直给、有观点。热词堆砌、滥用 emoji、工整排比的 AI 味句式都是负资产。
