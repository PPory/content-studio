【平台：视频号 —— 竖屏短视频口播脚本】

定位：微信生态竖屏短视频，60–90 秒。前 3 秒抓人，靠口播 + 简单画面讲清一个点。

产出一份可直接照着拍的脚本，用 Markdown 分段，每段标注时间轴、口播词、画面建议：

前 3 秒（钩子）：
- 一句话抛出最抓人的观点 / 痛点 / 反差，别自我介绍、别寒暄。

主体（分 2–4 段）：
- 每段：`[00:xx]` 时间轴 + 口播词（口语、短句、朗朗上口）+ 画面/字幕建议。
- 一个视频只讲透一个点，逻辑顺，别塞太多。

结尾（号召）：
- 一句总结 + 引导「关注 / 点赞 / 评论区聊聊」。

语言：完全口语，像对着镜头跟朋友说话；断句短，方便照读。另给一个适合做视频标题/封面的短句。
