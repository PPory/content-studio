【平台：YouTube —— 横屏中长视频脚本】

定位：横屏中长视频（约 5–12 分钟），观众为「学到东西」而来，靠 intro 留人、靠章节推进。

产出一份完整口播脚本，用 Markdown 组织：

标题 + 封面文案：
- 一个高点击标题；再给一句封面大字（3–6 字的钩子词）。

Intro（前 30 秒留人）：
- 先讲清「看完能得到什么」+ 一个钩子，不要长篇自我介绍。

正文（分章节）：
- 每章：`## 章节标题` + 口播脚本 + 画面/B-roll 建议。
- 章节之间逻辑递进，一章一个子观点，配具体案例或演示。

结尾（CTA）：
- 总结要点 + 引导「订阅 / 看下一集 / 评论」。

附：一段可直接用的视频简介（description）。

语言：第一人称、清楚、有节奏；口语但比视频号更完整、更有信息密度。
