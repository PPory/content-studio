# 情报能力盘点与改造方案

2026-09-07。范围：当前 content-studio 分支、实际配置是否存在、公开接口只读验证。未启动付费采集、真实模型研究或定时任务。配置只记录有无，不记录密钥。

## 结论

已有采集基础，但没有串成“关注方向 → 主动调研 → 连接个人知识 → 选题候选 → 用户采用”的完整链路。优先复用采集适配器、来源真实性校验、Wiki 连接和本地任务队列；不沿用旧 vault 报告存储，也不把目前的素材拼接当 AI 调研。

## 必须修正的断点

1. `server/routes/local-support.mjs` 的 `generateInsight` 取最近 12 条素材，截取正文后拼接，写成 knowledge_item；`POST /api/insights/run` 未调用搜索或模型。应由真正的调研任务替代，不继续把它作为周度智能洞察。
2. `server/routes/local-content.mjs` 的 `/api/insights/candidates` 取前 8 条素材映射卡片，不是调研或选题推理结果。新选题卡必须绑定研究记录和证据。
3. 旧 personal-intelligence-radar 依赖固定 vault、Markdown 周报和命令执行；Pi 当前显式加载 `.agents/skills`。不能只重写旧文案就认为 AI 已接入。
4. 热点工具以榜单和摘要为主，受众采集又只接受困惑原话；事件变化、方法资料、个人经历需要保留独立类型，不能塞进同一个“用户问题”证据定义。
5. 接口失败、只读到摘要、部分来源成功必须进入调研覆盖记录，不能以空列表或“已完成”掩盖。

## 本轮已落实的 Skill 调整

- 新增 `.agents/skills/intelligence-research`：当前 AI 可发现、可读取；用实际存在的热点、搜索、公开读取、附件与知识检索工具进行按需调研，在对话中给候选。
- 更新 topic-clustering：专注用户已给材料，按问题和判断构造角度；主动外搜交给调研 Skill。
- 旧雷达明确标记历史状态，保留有价值的抓取代码；未删除旧报告或任何来源数据。
- douyin-data 实际是本人账号的运营数据导入，且依赖旧浏览器工具，不是抖音选题调研，本轮不把它迁入情报。
- material-gap 仍服务文章证据缺口；事实核查、材料提取继续复用，不重写成重复的总控 Skill。

新 Skill 不注册定时任务、不启动旧收费脚本、不写正式 Wiki；对话候选并不等于产品里的持久化选题卡。它是当前可用入口，不是后台调研已经完成的声明。

## 下一阶段的执行设计

### 1. 一个关注方向，一次可追溯调研

关注方向记录问题、主题、平台 / 账号 / 社区范围、频率、时间窗口、请求预算和排除项。配置由用户确认后复用，不让用户逐个平台阅读。先支持“立即调研”，闭环通过后再接日 / 周调度。

研究执行依次进行发现、取原文、去重与分类、连接知识、形成候选。原文没有读到时允许保留线索，但不能形成假引文。重跑复用已有采集任务和原始快照，避免重复收费。

### 2. 明确保存四类对象

- 关注方向：用户认可的长期调研范围与预算。
- 调研记录：实际来源覆盖、时间、步骤、失败、成本与可恢复的 provider run / snapshot ID。
- 来源证据：URL、平台、时间、原文或摘录、读取层级、内容哈希；区分原话、新闻、个人笔记和 AI 推断。
- 选题候选：问题、读者、为什么值得关注、知识连接、角度、证据、缺口、关联旧卡与下一步。候选可持续更新；采用才进入选题空间。

这些是业务对象，使用 SQLite，不在 Skill 目录存 config.json、周报 Markdown 或第二套任务状态。新数据契约先落领域和 API，再做页面；沿用已有真实性校验，避免同一规则多份实现。

### 3. 情报页成为结果入口

默认“选题发现”，旁边“收集箱”和“关注与调研”。平台作为来源配置与筛选。卡片首屏只显示问题、价值、个人连接和下一步，展开看来源；同一事件的新证据更新旧卡。资料池不等于待写列表。

### 4. 验收标准

- 一次真实调研能从至少一个可用来源读到原文、连接真实 Wiki（无匹配允许空）、输出可解释的候选。
- 部分来源失败仍交付覆盖清单，不虚构评论和引文；零候选是有效结果。
- 同一调研重试不会重复计费触发已完成的采集，也不会重复建卡；重启可恢复。
- 用户采用后携带来源与研究上下文进入选题空间，已有讨论和正文不丢失。
- 所有写数据的验证使用系统临时隔离工作区；付费采集按确定的范围与预算再验收。

## 本轮验证范围

公开源检查已执行；付费提供商仅验证配置和调用代码。新增 Skill 进行格式校验、运行时发现 / 读取测试；没有以无模型测试代替真实调研效果验收。
