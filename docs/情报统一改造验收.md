# 情报统一改造验收

日期：2026-09-22。分支：`experiment/content-bridge`。未合并 main，未推送或部署。

## 交付的使用方式

情报只有一个日常阅读入口，主要切换为推荐和已收藏。默认展示8条，继续加载仍取同一集合中通过检查的内容；来源、未读、历史、忽略和搜索按需展开。原始资料、信源工具和处理详情退到次级入口，取消独立的前台审阅队列与情报选题清单。

卡片突出事件、推荐理由与出处；详情保留原文、引用、发布时间与首次采集时间、结论限制和持续讨论。读失败不标已读，忽略可撤销，返回恢复阅读范围和位置。原始资料以文章和讨论的实际身份展示，全量分页搜索，没有只搜索最近500条的截断。

用户直接把一条或多条情报加入内容选题，也可加入已有选题、补充想法或选择有依据的表达角度；保存不以模型生成成功为前提。收藏不自动转成选题。一次操作重试复用结果，主动另选角度可另建选题。来源、版本、想法与不能声称的结论独立保存，不塞入系统标识到正文。

## 内部链路及历史兼容

更新情报串联已启用来源采集、原文去重、相关性与可读性、语义整理、证据范围复核和稳定卡片。定时采集完成后使用同一整理流程；未额外开启付费源、定时频率或外发授权。超过8份材料分批推进，按内容及规则指纹缓存，自动失败最多尝试两次；用户主动再次更新可重新尝试，模型恢复后不再永久遗漏。未完成和无授权不会冒充精选。

同一事件更新保留收藏、忽略、已读版本、讨论与选题关系。人工拆分后的两侧都会重新整理，不再自动合回；人工合并保留规范ID及旧ID映射。中断中的处理可重新进入有上限的重试。该恢复基于现役单工作区运行器的串行消费，不支持多个应用进程同时写同一库的额外并发租约。

历史已确认的情报选题与知识机会在内容选题可见，打开时复用已有关联；未确认候选不自动采用。旧情报选题入口转向内容选题，旧待选卡片链接回到对应卡片选择；旧详情仍可解析别名，旧设置和资料链接分别进入设置与原始资料。知识探索继续从内容选题进入。

来源过期、删除或AI权限撤回时，派生卡片/历史缓存遮罩；相关助手读取与发送会重新校验。研究复制许可撤回时禁止读取/覆盖可能含原文的旧研究正文，保留底层数据以便恢复。摘要和外发上下文也校验AI许可。

新增迁移33—35只增加处理状态、选题意图及旧ID映射。已有库升级前生成 SQLite 恢复点，核对完整性、外键、逐表数量和SHA256；备份失败停止升级。没有清空旧表或批量删除数据。
