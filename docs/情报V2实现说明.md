# 情报 V2 实现说明

依据「诊断情报系统」方案，在现有 SQLite、情报运行器和研究空间上增量升级。旧 ID、正文、简报版本、用户反馈、研究关联与归档记录保留。

## 数据与兼容

- 迁移 0027 为来源增加出处身份、渠道、评论父级、正文指纹、原文版本和发布主体；增加主题聚合与成员、反馈事件；为简报和候选卡增加审核、时效和准备状态。旧来源在打开工作区时按确定性规则补齐，未知字段保持未知，不调用 AI 猜测。
- 迁移 0028 增加 `intel_channels`。内置目录在工作区初始化时幂等创建；读取渠道接口不写入。用户选择启停，人工渠道不能开启自动采集。未修改的内置目录属于空工作区基线，可以导入便携备份；用户修改、自定义信源或采集历史仍按已有数据保护，不允许被便携导入覆盖。
- `intel_runs`、`intel_steps`、现有任务队列继续记录处理批次，不重复建立 `intel_jobs`。编辑和范围复核记录规则版本、模型与返回的 token 用量；没有账单数据时成本为空。
- `intel_briefs` 继续保存单条精选及历史版本；新正文不覆盖已有来源正文。旧未审核简报标记为待复核，同一份证据补齐范围复核后可升级该简报版本。
- 新闻不一定有 Wiki 与受众问题，因此情报选题复用 `intel_cards`，确认后标记为已保存，保留 `research_id`。既有 `content_opportunities` 的强制引用规则保持有效，新增 `planning_json` 与 `readiness` 供统一视图使用；旧记录不因 `active` 或 `fit=strong` 自动变成可开始。
- 多条简报、来源指纹和版本保存在候选卡结构化数据内；确认研究后建立简报与研究关系，并带入原文、Wiki 和讨论。预览无数据库写入，保存和开始研究分别核对确认标志和原文版本。

## 采集与质量

内置 28 个渠道：25 个自动适配、3 个人工入口，默认启用 12 个。覆盖官方、实践、受众问题、深度、邻近探索及中英文来源。Ask HN 使用第三方 hnrss 转发并保留原发布主体。目录验证只是地址与解析验证，运行页面显示各渠道实际成功、失败、无新内容或未变化状态。

每渠道每次最多读两篇原文；单次 HTTP 有 15 秒超时、2 MB 上限和逐跳公开网址检查；服务错误最多重试一次，订阅缓存仅完整成功后推进。304 可复用时间窗内已采集原文，避免前次模型失败后再刷新时丢失输入。RSS 摘要不能作为已读原文，人工入口只打开原站。

来源身份与采集方式分开。确定的本地记录、与草稿逐字相同的正文标为内部资料；评论不计独立外部依据，同帖、相同正文和明确同源关系不重复计数。原始出处仍无法确定的转载不能自动认定已获得独立验证。

处理链路为采集 → 来源身份 → 去重分组 → 主张及解读 → 范围复核 → 服务端保存检查 → 多样性排序。标题、摘要和主张的数字需出现在所引原文中；主张关联明确引文编号，来源自述需归属。范围复核检查样本、条件、归属和外推。未完成复核的内容留在历史与待复核中，不能进入本期精选。

合格候选按可用证据、用途及未读状态进行保守排序；同一主题一条、同一主体最多两条、总数最多八条。收藏和负反馈保留事件及原因，负反馈原因提供给后续编辑参考，未读不作为负反馈。排序并非真实性概率。

## 页面与操作

主要入口是精选、选题、资料。关注设置、信源管理、处理记录为次级入口；AI 热点、周报、旧研究和知识选题深链继续可用。资料合并最近 500 条采集记录、灵感种子与已收藏情报，原对象仍独立保存。

精选可以单条或多条预览选题。预览显示读者、角度、交付物、研究待办和不可声称的结论；没有合适结果允许为空。确认保存后进入统一选题列表。待补证选题可以开始研究，缺口与限制一起带入；开始研究不自动建立文章，后续沿原有研究空间创建文章。

## 验证与边界

`npm run test:intelligence:v2` 覆盖迁移与正文版本、评论和自有稿件、有效及无效证据、范围复核、预览无写入、确认和重复提交，以及真实本地 API、数据库和浏览器中的保存、重开、研究与文章创建。浏览器覆盖小屏幕和失败状态；模型 HTTP 回包在端到端测试中使用隔离桩，不能作为外部模型质量验收。

本次验证完成了项目检查、全部单元测试脚本、Pi 运行时、扩展、窗口退出、全部现有浏览器测试脚本，以及新增 V2 领域、渠道、页面和真实接口端到端测试。发现的备份基线与资料带入研究兼容问题已修复，从失败点续跑通过；最终构建和差异格式检查通过。桌面及 390px 截图保存在 `workbench/output/playwright/`。

本版不自动启用定时采集，不新增付费社媒授权；凭据沿用本机已有配置。语义复核仍是 AI 检查，无法替代实验复现。近义转载、复杂转述依赖分组与复核，不宣称已具备全面事实核验。暂未提供自动撤稿检测、跨渠道语义近重复阈值学习和精确费用账单；原始证据与版本保留可供人工复核。
