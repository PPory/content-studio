# 从已有材料构造选题

先读取真实条目，围绕共同问题、冲突或判断组合，不按表面关键词归类。允许从知识解释现象、个人经历引出问题、事件变化形成研究假设等方向展开；知识连接不是所有候选的前置条件。

每个方向说明核心问题、目标读者、可能的表达角度、真实来源及已有知识连接、证据缺口和下一步。用户尚未表达的判断只能写成供讨论的假设，不代替用户表态。区分观察事实与推断，不预测爆款。

单条孤立内容不伪装成聚类，同一事件的转载合并并保留原始出处。没有自然连接可以返回空结果。不自动创建选题、写文章或更新 Wiki。

## 常见误区

- 聚类不是把每条素材改一个标题。
- 同一关键词不代表同一个用户问题；一个主题也可以产生不同受众和解释角度。
- 没有读取到历史候选，不能声称已完成跨期去重。
